# Ejercicios de C - UTN

Repositorio donde voy a guardar ejercicios y prácticas realizadas durante la
Tecnicatura en Programación de la Universidad Tecnológica Nacional (UTN).

## Contenido

En este repositorio se encuentran ejercicios realizados durante el aprendizaje
del lenguaje C, incluyendo diferentes conceptos de programación.

### Temas

- Variables y tipos de datos
- Condicionales
- Ciclos
- Funciones
- Vectores
- Matrices
- Búsqueda
- Ordenamiento
- Contadores y acumuladores
- Resolución de problemas

## Organización

Los ejercicios están organizados en carpetas según el tema o proyecto.

## Objetivo

Utilizar este repositorio para registrar mi progreso y evolución en el aprendizaje
de programación durante la carrera

## Sobre el repositorio

Este repositorio forma parte de mi proceso de aprendizaje como estudiante de
la Tecnicatura en Programación de la UTN.

Los ejercicios se irán incorporando a medida que avance en la carrera.
