# Ejercicio Integrador - Gestión de Reparaciones

## Descripción
Programa desarrollado en lenguaje C como ejercicio integrador de la materia de Programación I de la UTN.
El programa permite gestionar vehículos, registrar reparaciones y presupuestos, buscar vehículos por patente y generar un listado de códigos de reparación realizados.

## Conceptos utilizados

- Vectores
- Funciones
- Búsqueda
- Ordenamiento
- Ciclos
- Condicionales
- `switch`
- Contadores
- Acumuladores

## Funciones principales

### `Buscar()`
Busca una patente dentro del vector y, si existe, devuelve su posición.

### `Ordenar()`
Ordena los códigos de reparación mediante el método de burbujeo.

## Nota
La constante `T` está definida como `2` para realizar pruebas durante el desarrollo. En el ejercicio original se trabajaba con 250 vehículos.
